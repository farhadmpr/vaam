# مدیریت اقساط وام (Vaam)

اپلیکیشن فلاتر برای ثبت و مدیریت اقساط وام‌های بانکی با تقویم شمسی و نوتیفیکیشن یادآوری.

## ✨ امکانات

- **ثبت وام** با فیلدهای: نام (یکتا)، بانک، تاریخ شروع اقساط (شمسی)، تعداد اقساط، مبلغ هر قسط (اختیاری) و توضیحات
- **تولید خودکار اقساط ماهانه** از تاریخ شروع (با اصلاح خودکار روز؛ مثلاً ۳۱ شهریور → ۳۰ مهر)
- **صفحه اصلی**: لیست اقساط پرداخت‌نشده مرتب‌شده از نزدیک‌ترین سررسید به دورترین، همراه با نشانگر «امروز / فردا / n روز مانده / عقب‌افتاده» — تعداد اقساط نمایش‌داده‌شده محدود است (پیش‌فرض ۱۰؛ قابل تغییر در تنظیمات)
- **جستجو** در صفحه اصلی و صفحه وام‌ها بر اساس نام وام، نام بانک و توضیحات (بدون حساسیت به حروف بزرگ/کوچک، ارقام فارسی/انگلیسی، «ي/ك» عربی و نیم‌فاصله؛ جستجوی چندواژه‌ای با منطق «شامل همه واژه‌ها»)
- **علامت‌گذاری قسط به‌عنوان پرداخت‌شده** (با امکان برگرداندن از طریق SnackBar)
- **ویرایش و حذف وام**؛ در صورت تغییر تاریخ شروع یا تعداد اقساط، اقساط از نو ساخته می‌شوند و وضعیت پرداخت اقساطی که شماره یکسانی دارند حفظ می‌شود
- **نوتیفیکیشن یادآوری**: در روز سررسید هر قسط و در ساعت تنظیم‌شده نمایش داده می‌شود
- **تنظیمات نوتیفیکیشن**: فعال/غیرفعال کردن، انتخاب ساعت نمایش و نوع نوتیفیکیشن (پیش‌فرض سیستم، با صدا، فقط لرزش، بی‌صدا) + ارسال نوتیفیکیشن آزمایشی
- **تنظیم تعداد اقساط صفحه اصلی**: محدودیت نمایش اقساط پرداخت‌نشده در صفحه اصلی (پیش‌فرض ۱۰، بازه مجاز ۱ تا ۲۰۰)
- **پشتیبان‌گیری و بازیابی**: تهیه فایل پشتیبان JSON (شامل همه وام‌ها و اقساط با وضعیت پرداخت) در محل انتخابی کاربر و بازیابی کامل اطلاعات از فایل پشتیبان (با تأییدیه و زمان‌بندی مجدد نوتیفیکیشن‌ها)
- **تقویم شمسی** برای دریافت و نمایش تاریخ‌ها (بسته‌های `shamsi_date` و `persian_datetime_picker`) — نام ماه‌ها و سال در تقویم هم شمسی است (شهریور ۱۴۰۵) با فعال‌سازی `PersianMaterialLocalizations.delegate`
- **فونت وزیرمتن** در تمام صفحات
- نوتیفیکیشن‌ها پس از **ری‌استارت دستگاه** مجدداً زمان‌بندی می‌شوند و با لمس نوتیفیکیشن، صفحه جزئیات همان وام باز می‌شود

## 💾 پشتیبان‌گیری و بازیابی

- **تهیه پشتیبان** (صفحه تنظیمات): یک فایل JSON شامل همه وام‌ها، اقساط و وضعیت پرداخت آن‌ها ساخته و کاربر محل ذخیره را با فایل‌منتخابر اندروید انتخاب می‌کند (نام پیش‌فرض: `vaam-backup-YYYY-MM-DD.json`)
- **بازیابی**: کاربر فایل پشتیبان را انتخاب می‌کند؛ پس از تأیید، تمام اطلاعات فعلی حذف و با پشتیبان جایگزین می‌شود و نوتیفیکیشن‌ها از نو زمان‌بندی می‌شوند
- ساختار فایل: `{"app": "vaam", "backupVersion": 1, "exportedAt": ..., "loans": [...], "installments": [...]}`

## 🏗 ساختار پروژه

```
lib/
├── main.dart                     # نقطه شروع، تم، لوکالیزیشن فارسی، هندل لمس نوتیفیکیشن
├── models/
│   ├── loan.dart                 # مدل وام
│   └── installment.dart          # مدل قسط
├── services/
│   ├── backup_service.dart       # تهیه/بازیابی فایل پشتیبان JSON (file_picker)
│   ├── database_service.dart     # ذخیره‌سازی SQLite (sqflite)
│   ├── settings_service.dart     # تنظیمات (shared_preferences)
│   └── notification_service.dart # زمان‌بندی نوتیفیکیشن‌ها (flutter_local_notifications)
├── utils/
│   ├── amount_input_formatter.dart # فرمتر مبلغ با جداکننده هزارگان
│   ├── search_utils.dart         # نرمال‌سازی متن برای جستجوی فارسی
│   └── jalali_utils.dart         # ابزار تقویم شمسی، ارقام فارسی، قالب‌بندی
└── pages/
    ├── home_page.dart            # صفحه اصلی (اقساط پرداخت‌نشده)
    ├── loans_page.dart           # لیست وام‌ها
    ├── loan_form_page.dart       # فرم ثبت/ویرایش وام
    ├── loan_details_page.dart    # جزئیات وام و اقساط آن
    └── settings_page.dart        # تنظیمات نوتیفیکیشن
```

## 🔔 نحوه کار نوتیفیکیشن

1. پس از هر تغییر (ثبت/ویرایش/حذف وام، علامت‌گذاری قسط، تغییر تنظیمات) همه نوتیفیکیشن‌ها از نو زمان‌بندی می‌شوند.
2. برای هر قسط پرداخت‌نشده‌ای که سررسید آن در آینده است، یک نوتیفیکیشن در «روز سررسید + ساعت تنظیم‌شده» زمان‌بندی می‌شود (حداکثر ۱۰۰ قسط آینده).
3. سررسیدهای گذشته نوتیفیکیشن ندارند؛ در صفحه اصلی با برچسب «عقب‌افتاده» نمایش داده می‌شوند و هنگام شروع برنامه هشدار جمعی ارسال می‌شود.
4. اگر مجوز «آلارم دقیق» (SCHEDULE_EXACT_ALARM) داده نشده باشد، به‌صورت نادقیق (inexact) زمان‌بندی می‌شود.

## 📱 پیکربندی اندروید

در `android/app/src/main/AndroidManifest.xml`:

- مجوزها: `POST_NOTIFICATIONS`، `VIBRATE`، `SCHEDULE_EXACT_ALARM`، `RECEIVE_BOOT_COMPLETED`، `WAKE_LOCK`
- Receiverهای `ScheduledNotificationReceiver` و `ScheduledNotificationBootReceiver` برای زمان‌بندی مجدد پس از ری‌استارت
- حداقل نسخه اندروید: **API 24** (نیاز پلاگین flutter_local_notifications نسخه 22)
